## Workflow (once submodule + patches exist)

```bash
./scripts/apply-patches.sh   # applies patches, fails loudly on conflict
cd upstream/libslic3r && cmake -B build && cmake --build build
```

## Updating upstream

```bash
cd upstream/libslic3r
git fetch origin
git checkout <new-tag-or-commit>
cd ../..
./scripts/apply-patches.sh
# fix any patch conflicts, regenerate the patch files via git diff
```

After updating, run the regression suite. Any divergence requires goldfile review per `DETERMINISM.md`.
