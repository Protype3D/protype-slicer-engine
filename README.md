# Protype Slicer engine source

This repository publishes the source code of the slicing engine behind
Protype Slicer (`protype-slicer-daemon`), under the GNU Affero General Public
License, version 3 or any later version.

The source of every release is added here as one commit and one tag,
`slicer-vX.Y.Z`, when that release of Protype Slicer is published. Each tag
carries its own README, build instructions, license and notices.
